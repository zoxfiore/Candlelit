# Asset credits

All assets in this folder were **AI-generated** for this project:

| Folder | Content | Format |
|---|---|---|
| `characters/` | 15 character images (cut-out style, transparent background) | PNG |
| `props/` | 6 flat objects: brain jar, microscope, newspaper, glial-cell board, portrait, plaque | PNG |
| `textures/` | 8 tileable textures: wood, plaster, tiles, bricks, checker floor, road, sand, night sky | JPG / PNG |
| `models/` | 23 low-poly 3D models: furniture, autopsy table, beer cooler, cider box, Buick, display case, lamp... | glTF binary (.glb) |

The code that loads, places, lights and animates them is in `src/` and `stories/`.
